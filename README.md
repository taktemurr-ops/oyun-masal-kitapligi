# Masal Kitaplığı · Fable Library

Resimli kısa masallar: birlikte oku, sonra sırala.

Ezop masallarından kısa anlatımlar (kamu malı). Sayfaları çevir; konuşma balonu düğmesi sözcükleri sırayla vurgular. Son sayfada resimleri masaldaki sırayla seç.

100.000 bölüm; her bölüm tohumdan üretilir ve yapay oyuncuyla doğrulanır. 33 dil. Eğitici ve Çocuk merkez uygulamasının oyunu; ortak motor: [egitici-motoru](https://github.com/taktemurr-ops/egitici-motoru).
